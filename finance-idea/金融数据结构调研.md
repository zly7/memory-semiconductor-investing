## 按使用场景选

**A 股 / 中文金融数据：先看 AKShare，其次 adata，再看 TuShare。**
AKShare 覆盖面最大、文档中文、更新近；adata 更像“面向个人量化的 A 股数据库”；TuShare 是老牌，但现在很多接口实际会涉及 token/积分/Pro 权限。([GitHub][4])

**全球股票/ETF/指数：先看 yfinance + FinanceDatabase。**
yfinance 负责拉行情/财务/期权等，FinanceDatabase 负责找全球 symbol universe。注意 yfinance 不是官方 Yahoo API，README 已经明确提醒个人用途和条款风险。([GitHub][3])

**更稳定的官方 API 免费额度：Alpha Vantage / Finnhub / Twelve Data / Alpaca / Tiingo。**
这类一般要 key，免费额度有限，但比纯网页抓取更适合做服务化。Alpha Vantage 明确是 free API key；Twelve Data 明确需要 API key；Alpaca 注册免费但股票行情权限看计划；Tiingo 和 Finnhub 也是 key-based API。([GitHub][7])

**加密行情：ccxt + cryptofeed。**
ccxt 是统一交易所 REST 接口事实标准；cryptofeed 更适合实时 websocket feed；Binance connector 适合只接 Binance。([GitHub][2])

## 我的推荐组合

如果你要做一个 **免费金融数据抓取/分析 Demo**：

```text
A股：AKShare + adata
全球股票：yfinance + FinanceDatabase
宏观/因子：pandas-datareader
加密：ccxt
统一封装：OpenBB
备用官方免费额度：Alpha Vantage / Finnhub / Twelve Data
```

如果要做 **相对稳定的生产数据管线**，不要只依赖 yfinance/网页抓取；建议至少做多源 fallback：`yfinance -> Alpha Vantage/Finnhub/TwelveData -> 本地缓存`，A 股则 `AKShare -> adata/TuShare -> 本地 parquet/duckdb`。

## 国际通用（全球市场 / 加密）

**OpenBB**（`OpenBB-finance/OpenBB`）— **68.1k ⭐** / 6.9k fork，今天仍在更新
这是目前这个赛道 star 最高的项目。面向分析师、quant 和 AI agent 的金融数据平台，主打 "connect once, consume everywhere"，把专有/授权/公开数据源统一接入，可同时暴露给 Python、Excel、MCP server 和 REST API。对你做 AI agent 接数据特别友好，原生支持 MCP server。

**ccxt**（`ccxt/ccxt`）— **42.7k ⭐** / 8.7k fork，今天仍在更新
加密货币交易 API，支持 100+ 交易所，提供 JavaScript / TypeScript / Python 多语言版本。如果你要的是数字货币行情/下单，这个是事实标准。

**yfinance**（`ranaroussi/yfinance`）— **23.9k ⭐** / 3.3k fork
Yahoo Finance 数据下载器，美股/全球股票最常用的免费入口，pandas 友好。注意它是非官方封装，Yahoo 接口偶尔会变动导致临时失效。

**qlib**（`microsoft/qlib`）— **约 28–30k ⭐**（API 限流未拉到精确值）
微软出品的 AI 量化投资平台，覆盖数据处理、模型训练、回测全链路，支持监督学习、市场动态建模和 RL。严格说它是量化框架而非纯数据接口，但自带数据层。最近因为集成了 R&D Agent（自动化研究找 alpha）热度飙升。这个跟你之前关注的 AI infra 方向挺契合。

## 中文社区（A 股 / 国内市场）

**AKShare**（`akfamily/akshare`）— **19.8k ⭐** / 3.2k fork，今天仍在更新 ✅
基于 Python 的开源财经数据接口库，覆盖股票、期货、期权、基金、外汇、债券、指数、加密货币的基本面与行情数据。特点是**完全免费、无需注册、数据源广**（东方财富、新浪财经、金十数据等），缺点是稳定性依赖源网站。还提供 AKTools（HTTP API 版本）突破 Python 限制。**这是目前国内最活跃、最推荐的免费选择。**

**Tushare**（`waditu/tushare`）— **15.0k ⭐** / 4.4k fork
A 股数据老牌项目。⚠️ 注意两点：一是主仓库 **最后一次提交停在 2024-03**，新接口都迁到了 Tushare Pro；二是Pro 版数据规范、质量高、社区活跃，但部分高级接口需要积分。实务中常见做法是 **Tushare + AKShare 双数据源互补**——Tushare 出规范数据，AKShare 兜底免费源。
